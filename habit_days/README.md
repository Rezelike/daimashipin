## 数据来源（事实核对表：`six-videos` 分支的 `six/facts/02_habit_days.md`）
- **Lally、van Jaarsveld、Potts、Wardle 2010**，《European Journal of Social Psychology》40(6):998–1009：伦敦（作者在 UCL）用邮件招的 96 人（除 2 人外都是研究生，平均 27 岁），每人自选一件还没在做的吃、喝或运动的小事，挂在每天一次的场景后（例：午饭时吃一个水果、晚饭前跑 15 分钟），84 天里每天上网报做没做，并填 7 道「自动化」题（0–42 分）。82 人可分析，39 人的曲线拟合得好。
  - 到顶（到自己顶点的 95%）：中位 66 天，最快 18 天，最慢 254 天；研究只有 84 天，超过 84 天的是曲线推算（表 2）
  - 第 21 天约 2/3：用表 2 的中位参数（a = 35、b = 30、c = 0.042）代进论文的曲线算的 65%，是**估算**，片里标了「按论文的曲线估算」；路的形状也是这条中位曲线
  - 曲线清楚的 39 人在有记录的日子里中位做到 88%，其余三组 60–63%（表 1），相关，不是因果
  - 漏做一次只掉 0.29 分（满分 42），55 人一共漏做 140 次（p.1006）
- **Keller 等 2021**，《British Journal of Health Psychology》26(3):807–824：192 人随机分「挂在日常的事后面 / 定钟点」，到顶的中位数 60 天对 59 天，所以片里说「定个钟点也行，两种挂法差不多」
- **Gardner、Lally、Wardle 2012**，《British Journal of General Practice》62(605):664–666：给病人的建议，约 10 周会变成自动的，所以总结写「按 10 周准备」
- **Singh 等 2024**，《Healthcare》12(23):2488：系统综述，只有 4 项研究报告了多久养成，中位 59–66 天；作者建议按 2–5 个月准备
- 「21 天」：Maltz 1960《Psycho-Cybernetics》序言（经 Gardner & Meisel 2012 UCL 博客转引）：整形病人约 21 天看惯新脸，没有研究数据
- 没说的话：「66 天人人适用」「21 天什么都没变」「有人练了 254 天」「到顶 = 满分」

## 重新出片
```bash
bash tools/build.sh                                             # 约 2 分钟：音效 -> 逐帧 -> MP4 -> 第 0 帧 -> 备用封面
.venv/bin/python tools/verify.py out/21天能养成习惯吗_75s_1080p.mp4  # 响度 / 真峰值、音效卡拍、画面卡拍、画面抖不抖
node tools/render.mjs --lint                                    # 每 0.25 s 查一遍：字出画、字互相压住、道具互相压住、字压在他头上（都应为 0）
node tools/sheet.mjs --mp4 out/21天能养成习惯吗_75s_1080p.mp4      # 分镜预览（--times 0,1.5,3 --out build/quick.png 只截这几个时间点）
node tools/render.mjs --stills 0,2.2,4.5                        # 只看几帧，输出到 build/stills/
node tools/render.mjs --covers                                  # 只出备用封面（会查竖封面那块的留白和左下角）
```
- 第一次运行会在这里建 `.venv`，装 numpy 和 imageio-ffmpeg（自带 ffmpeg）。还需要 Node 18 以上和 Chromium：Kiro 沙箱里都有，脚本会自动找到；在别的电脑上，先在这个目录 `npm i playwright-core`，再把 `CHROME_EXE` 指向本机的 Chrome。
- 画面：`src/stage.js`（天空、日出、远山、路和镜头；路就是习惯曲线 `habitE`）、`src/walker.js`（让小人在坡上走：一拍一步、腿用两段 IK 踩在路上）、`src/scene.js`（时间轴、开场、答案段）、`src/sections.js`（①②③ 和照着做）、`src/props.js`（天数牌、旗、进度条、路牌）。时间都按拍写。
- 小人：`src/figure.js` 是 `kit/figure.js`（`six-videos` 分支）的拷贝，按计划不直接引用 `kit/`；加了三处：轮廓光可以放在他前面（迎着日出）、脚可以贴着坡面、骨盆位置可以直接给（给 IK 用）。
- 工具：`tools/` 从 `bedtime_words/tools/` 复制；`render.mjs --lint` 的道具检查和 `verify.py` 来自 `music_study`（`music-study` 分支，PR #22，还没合并），`verify.py` 另加了响度和真峰值。
- 音效：`tools/audio.py`，cue 表在 `cues()`，共 210 个；第 0 帧一声重击，每一步一声脚步；混音后按响度（BS.1770）统一到 -18.4 LUFS。
