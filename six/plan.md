## 共同规则
- **一个人，成年人比例**：`kit/figure.js`（复制进本期 `src/`，别直接引用 `kit/`，以后改 kit 不影响已发的片）。画法见每条：A 扁平插画 / B 霓虹线条 / C 剪影 + 轮廓光（用户 10-31：「A,B,C 的风格我都想要」）。不坐在桌前、凳子上写作业、读书、拿练习题写（Skill 2.5）。开头也只有他一个人；比较两组时，用记分牌、两叠卡这类道具代表另一组。
- **每条自己的舞台和版式**：不复用前几期的面板、描边编号、柱子、挂钟、计时环、闹钟、日历、清单表、单词卡网格、窗户；这 6 条之间也不互相复用。
- **节奏骨架**（128 BPM，1 拍 = 0.469 s，160 拍 = 75 s；照「睡还是背」，lessons 结论 13）：
  | 拍 | 秒 | 事件 |
  |---|---|---|
  | 0 | 0.00 | 第 0 帧：两行问题（≤ 10 字）+ 他已经在动 + 重击音 |
  | 4.5 | 2.11 | 揭晓 1，这一屏停 4 拍 |
  | 8.5 | 3.98 | 揭晓 2（拉开或反转） |
  | 10.5 / 11.5 | 4.92 / 5.39 | 打勾 + 另一边的标签；约 6.1 s 出来源 |
  | 17 | 8.0 | 第二行翻成答案，他演答案，弹出 ①②③ 三个标签 |
  | 26.5 | 12.4 | 证据小卡 |
  | 32 / 64 / 96 | 15 / 30 / 45 | 三步，每步他演一个场景，没有 STEP 页 |
  | 128–160 | 60–75 | 边演边出总结（最后一屏），指着它，收尾动作，75 s 直接结束 |
- 画面上不放点赞、收藏、关注、评论提示；只有音效、没有配乐，每个画面事件一个音效，混音 -18.4 LUFS；画面不抖。
- 字体读 `sleep_or_cram/assets/fonts/`；工具从 main 上最新一期复制（`bedtime_words/tools/`；`music_study/` 合并后用它的，带 `verify.py`）。

- 发布顺序（画法轮流，相邻两条不同）：1 A → 2 C → 3 B → 4 A → 5 C → 6 B。三种画法各两条，发完可以按画法比 2 秒跳出、5 秒完播、平均观看（题目不同，只当参考）。
