# 午睡醒来，反而更懵？（75 s）

`six/plan.md`（`six-videos` 分支）里的第 4 条，画法 A。结构和拍点照「睡还是背」（lessons 结论 13）：第 0 帧两行问题 + 他已经在动 + 重击，2.11 s 揭晓 1、3.98 s 揭晓 2、4.92 s 打勾，8 s 出答案，15 / 30 / 45 s 三步，60 s 起边演边出总结，75 s 直接结束。
舞台是这期自己的：一池水，睡得越久床垫沉得越深（越深 = 深睡越多），醒来要从深处慢慢浮上来。道具都是这期新画的：黄色充气床垫、水深刻度「睡了几分钟」、岸上三块记分牌、从水里冒出来的气泡标签、躺下 → 入睡 → 睡着的时间条和手机、水面上一个个破掉的气泡、窗帘和照进来的光、「把符号换成数字」的板子。没有用前几期的柱子、挂钟、计时环、闹钟、日历、HUD 面板、描边编号、清单表、单词卡和窗户。
只有一个成年人比例的小人（`src/figure.js`，从 `kit/figure.js` 复制，另加了坐、伸懒腰、发懵、捧水、拉窗帘、跳水、游泳这些姿势），每一帧都在；他不坐在桌前写作业，躺、坐、站、走、拉、捧水、跳。
1920×1080 / 30 fps / 75.000 s，H.264 + AAC，9.5 MB。只有音效、没有配乐，按 128 BPM 卡点。

## 数据来源（事实核对表：`six/facts/04_nap_length.md`，在 `six-videos` 分支）
- **Tietzel & Lack 2001**，《Sleep》24(3):293–300：12 名大学生，前一晚只睡约 4.7 小时；同一批人分别不睡、睡 10 分钟、睡 30 分钟（脑电判定的真睡着时间），下午 3 点左右醒。表 3 的符号—数字替换（90 秒，换对几个）：
  - 醒来 5 分钟：没睡 55.0，睡 10 分钟 65.3，睡 30 分钟 50.6，三组两两差异都显著 → 「比没睡还差」「一醒就好」
  - 醒来 35 分钟：54.4、66.9、60.8；30 分钟组比 5 分钟时显著回升，比没睡高但这项不显著 → 写「缓过来了」，不写「反超」
- **Brooks & Lack 2006**，《Sleep》29(6):831–840：24 名大学生，前一晚只睡约 5 小时，试了 5 / 10 / 20 / 30 分钟。醒来 5 分钟，7 项测验里好过没睡的：10 分钟组 5 项、30 分钟组 0 项；10 分钟总体最好。表 4：30 分钟的午睡里深睡（3 + 4 期）约 11.4 分钟，10 分钟的只有 0.9 分钟
- **Leong 等 2023**，《Sleep》46(4):zsad025：32 名平时睡得少的成年人，不睡 / 10 / 30 / 60 分钟。30、60 分钟组醒来 5 分钟做题变慢，30 分钟内恢复；60 分钟组醒来 5 分钟自己觉得不困，做题却最慢 → 「觉得醒了，不等于真醒了」
- **Hayashi 等 2003**，《Clinical Neurophysiology》（只读到摘要，10 人）：醒后见强光、洗脸有点用，洗脸效果小、持续短 → 片里写「小研究，效果小」
- 「为了记得牢睡 30–60 分钟」和「睡还是背」那期一致；「收拾桌面、翻一遍错题」是常见做法，板子上标了「常见做法」
- 不说的话：「超过 30 分钟没用」「20 分钟最佳」「咖啡 + 午睡」（观众有未成年人）；「10 分钟」都写成真睡着的时间

## 重新出片
```bash
bash tools/build.sh                                       # 约 1.5 分钟：音效 -> 逐帧 -> MP4 -> 第 0 帧 -> 备用封面
SKIP_FRAMES=1 bash tools/build.sh                         # 只改了 tools/audio.py：留着逐帧，只重做声音和 MP4（约 15 s）
.venv/bin/python tools/verify.py out/午睡更懵_75s_1080p.mp4  # 格式、响度、音效卡拍、画面卡拍、抖不抖、每帧都有小人（数字）
node tools/render.mjs --lint                              # 每 0.25 s 查一遍：文字出画、互相压住；道具出画、互相压住；字压在小人头上；小于 34 px 的列出来
node tools/sheet.mjs --mp4 out/午睡更懵_75s_1080p.mp4      # 分镜预览（--times 0,1.5,3 只截这几个时间点，输出 build/quick.png）
node tools/render.mjs --stills 0,2.2,4.5                  # 只看几帧（秒），输出到 build/stills/
node tools/render.mjs --covers                            # 只出备用封面（会查竖封面那块的留白和左下角）
```
- 第一次运行会在这里建 `.venv`，装 numpy 和 imageio-ffmpeg（自带 ffmpeg）。还需要 Node 18 以上和 Chromium：Kiro 沙箱里都有，脚本会自动找到；在别的电脑上，先在这个目录 `npm i playwright-core`，再把 `CHROME_EXE` 指向本机的 Chrome。
- 画面：`src/scene.js`（床垫和小人的整条时间线、标题、开场的记分牌、答案段的标签和深睡小卡）、`src/sections.js`（①②③ 和照着做），时间都按拍写；舞台和道具在 `src/props.js`（水池 `drawPoolBack` / `drawPoolFront`、刻度 `drawGauge`、床垫 `drawMattress`、记分牌 `drawScoreBoard`、气泡 `drawBubble`、窗帘 `drawCurtain`、板子 `BOARD`）；小人在 `src/figure.js`，`POSES` 里本期加的姿势在 `nap_length additions` 那一段。
- 音效：`tools/audio.py`，cue 表在 `cues()`，240 个，水声（气泡、水花、晃水）、手机震动、窗帘、脚步都是这期新合成的；第 0 帧一声重击；混音后按响度（BS.1770）统一到 -18.4 LUFS，和前几期一样；这期音效稀，软削波用 1.8（`DRIVE`）。
- 验证（`tools/verify.py`，这期新写的，查法和引擎的 VERIFY 一样）：75.000 s、1920×1080、30 fps、9.5 MB；-18.4 LUFS，真峰值 -2.8 dBTP；52 个能听出起音的音效，中位数偏拍 -0.5 ms，90% 在 6.4 ms 以内；画面里 80 处变化的起点，95% 落在半拍网格 ±2 帧内；拍上静止区域的额外变化平均 0.06 灰度（< 1.0，不抖）；2250 帧每帧都有小人。`render.mjs --lint`：出画 0、文字互相压住 0、道具互相压住 0、字压在小人头上 0。
