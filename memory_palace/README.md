# 记忆宫殿真的有用吗？（75 s）

`six/plan.md`（`six-videos` 分支）里的第 5 条，选题、分镜、画法用户 2026-10-31 已确认。画法 C（剪影 + 轮廓光），舞台是「夜里剖开的一栋房子，每处一盏灯」：一栋拿掉了正面墙的平房，从门口到床一共 10 个固定的点，每个点头顶一盏吊灯，这条路线就是记忆宫殿。72 个词的成绩画成右上角一串 72 颗灯泡（亮 = 记住）。全片只有一个成年人，开头也只有他；他接落下来的词、走路线、指、低头回想、走出门举起双手，不坐下写作业、读书。③ 里他「在脑子里走一遍」画成一个半透明、冷色轮廓光的他自己（虚影），揭晓 2 的「练了 40 天」画成每个点上闪过的虚影。
1920×1080 / 30 fps / 75.000 s，H.264 + AAC，11.2 MB。只有音效、没有配乐，按 128 BPM 卡点（脚步声在拍上）；他在每一帧里。

## 数据来源（事实核对表：`six-videos` 分支的 `six/facts/05_memory_palace.md`）
- **Dresler 等 2017**，《Neuron》93(5):1227–1235：51 名没学过记忆法的慕尼黑男大学生，3 组各 17 人（记忆宫殿 / n-back / 不训练），每天 30 分钟 × 40 天。72 个具体名词，每个显示 2 秒，20 分钟后自由回忆（补充表 S2）：记忆宫殿组 26.5 → 62.5，n-back 组 31.3 → 42.7，不练组 29.5 → 36.6；4 个月后重学第一张词表：50.3；训练期间 5 分钟背随机词：第 1 天 16.6 → 最后一周 42.3（p. e5；片里曲线的形状是示意，只有两端是论文的数）；训练轮换 4 条路线
- **Twomey & Kroneisen 2021**，《Quarterly Journal of Experimental Psychology》74(8):1317–1326：13 项随机对照试验，g = 0.65（中等）
- **Ondřej 2025**，《British Journal of Psychology》：多数研究偏倚风险高；读书面文章时不如复述 → 「理解课本没证据」
- 「越夸张越好」「一个点放 1 样」标为常见做法（证据不一）
- 没说的话：「40 天记忆力翻倍」「4 个月后还记得 48 个」「人人都能」「练脑游戏没用」「大脑结构变了」

## 重新出片
```bash
bash tools/build.sh                                               # 约 2 分钟：音效 -> 逐帧 -> MP4 -> 第 0 帧 -> 备用封面
.venv/bin/python tools/verify.py out/记忆宫殿真的有用吗_75s_1080p.mp4  # 响度 / 真峰值、音效卡拍、画面卡拍、画面抖不抖
node tools/render.mjs --lint                                      # 每 0.25 s 查一遍：字出画、字互相压住、道具互相压住、字压在他头上
node tools/sheet.mjs --mp4 out/记忆宫殿真的有用吗_75s_1080p.mp4      # 分镜预览（--times 0,1.5,3 --out build/quick.png 只截这几个时间点）
node tools/render.mjs --stills 0,2.2,4.5                          # 只看几帧，输出到 build/stills/
node tools/render.mjs --covers                                    # 只出备用封面（会查竖封面那块的留白和左下角）
```
- 第一次运行会在这里建 `.venv`，装 numpy 和 imageio-ffmpeg（自带 ffmpeg）。还需要 Node 18 以上和 Chromium：Kiro 沙箱里都有；别的电脑上先在这个目录 `npm i playwright-core`，再把 `CHROME_EXE` 指向本机的 Chrome。
- 画面：`src/stage.js`（夜空、房子、10 个点的家具、吊灯和镜头）、`src/walker.js`（让小人在平地上双向走：一拍一步、腿用两段 IK）、`src/scene.js`（时间轴、开场、答案段）、`src/sections.js`（①②③ 和照着做）、`src/props.js`（灯串、落下的词、吊灯牌、门牌、购物单、牛奶 / 雨伞 / 钢琴、练习曲线、小卡）。时间都按拍写。
- 小人：`src/figure.js` 是 `habit_days/src/figure.js`（= `kit/figure.js` + 三处补充）的拷贝，按计划不直接引用 `kit/`。
- 工具：`tools/` 从 `habit_days/tools/` 复制（来源见那里），`audio.py` 的音效和 cue 表换成这一期的（共 263 个）；混音按响度统一到 -18.4 LUFS。
