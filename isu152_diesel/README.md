## 数据来源
- [俄文维基 ИСУ-152](https://ru.wikipedia.org/wiki/ИСУ-152)：V-2-IS 四冲程 V 形 12 缸柴油机，520 马力；对比表里 ISU-152 重 45.5–46 吨，公路最高 35 km/h；NK-1 高压油泵。
- [俄文维基 В-2](https://ru.wikipedia.org/wiki/В-2)：缸径 150 mm，行程 180 mm（左排）/ 186.7 mm（右排），38.88 升，压缩比 14 和 15，60° V 角，每排两根凸轮轴（DOHC），48 个气门，液冷；工作顺序 1л-6п-5л-2п-3л-4п-6л-1п-2л-5п-4л-3п（引自 T-34-85 技术手册）。
- 520 马力对应 2000 转：[Tank Archives 转载的 1944 年国防委员会第 6679 号决议](https://www.tankarchives.com/2019/12/more-power.html)。
- 压缩终了 500–600°C、燃烧 1700–1900°C（非增压）：[Argun 的 V-2 技术说明](https://argun-kazakhstan.com/products/v-2-battle-tank-engine)；[大英百科](https://www.britannica.com/technology/How-does-a-diesel-engine-ignite-fuel-without-spark-plugs)：柴油机压缩后的空气常超过 526°C。
- 岩浆最高约 1200°C：[USGS](https://www.usgs.gov/programs/VHP/temperatures-surface-reflect-temperatures-below-ground)。
- 计算：2000 ÷ 60 ÷ 2 × 12 = 每秒 200 次做功；2000 ÷ 60 ≈ 每秒 33 圈；720° ÷ 12 = 60°；单缸 π/4 × 15² × 18 cm³ ≈ 3.2 升（右排 3.3 升）。

示意的部分（画面为了看清做了简化）：连杆长度和副连杆铰点是按 180 / 186.7 mm 两种行程反推的示意值；气门正时用的是通用值；气缸编号的方向（哪头是 1 号）没有考证，按 1-5-3-6-2-4 这种顺序，从哪头数看起来都一样；凸轮轴的传动（锥齿轮和斜轴）没有画。

## 声音
`audio.py`：每一缸点火的那一刻合成一声爆燃（`mech.bang_events`，和画面读同一个曲轴转角），慢放时一拍一声低沉的「砰」，越快越密，实速时 200 声每秒连成轰鸣；左排偏左、右排偏右。四冲程特写里只有 L1 响，吸气、压缩（上升音）、做功、排气各一声。转场 whoosh、字幕 pop、第 0 帧一声 hit、实速落地一声 chime 用的是 `engine/sfx.py`。按响度（BS.1770）配平，整片 -18 LUFS、真峰值不超过 -1 dBTP。

## 重新出片
```bash
bash .kiro/skills/vibe-knowledge-video/scripts/setup_env.sh        # 环境（venv + ffmpeg）
V=/projects/sandbox/.videoenv/vpy
$V -m pip install -r isu152_diesel/requirements.txt                 # 再补 Pillow 和 fontTools
$V isu152_diesel/render.py --preview     # build/preview.png：24 张关键帧 + 文字检查（约 5 s）
$V isu152_diesel/render.py               # 成片 + 分镜预览 + 第 0 帧 + VERIFY（约 30 s）
$V isu152_diesel/render.py --audio       # 只重做声音，换进现有成片
```
- `mech.py`：节拍、曲轴转速和转角、工作顺序、主副连杆。改 `BPM` 后重出即可换节奏。
- `art.py`：每一小节的画面（坦克、V12 立体剖面、端面剖视、字幕、HUD）。
- `pix.py`：像素画布和字体。字体是 Fusion Pixel 12px（SIL OFL 1.1，许可证在 `assets/fonts/`），1 倍 = 成片 36 px，2 倍 = 72 px。
- VERIFY 会报：时长、分辨率、帧率、文件大小、响度、真峰值、4 个切点是否落在对应帧、最后一帧和第 0 帧的差（循环是否无缝）、音效和慢放爆燃声离拍点多远。
