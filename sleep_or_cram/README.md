# 学累了，睡还是背？（75 s）

1920×1080 / 30 fps / 75.000 s，H.264 + AAC。只有音效、没有配乐，按 128 BPM 卡点；开场之后每一帧都有小人。

- 成片：`out/睡还是背_75s_1080p.mp4`（点开后右上角下载按钮可下载）
- 第 0 帧：`out/封面_第0帧.png`
- 分镜预览：`out/分镜预览.png`（30 张关键帧拼图）
- 封面：用 ChatGPT 生成，提示词在 `out/封面提示词.txt`；先上传 `out/封面参考_3x4.png`（竖封面 1080×1440）或 `out/封面参考_4x3.png`（横封面 1440×1080）当构图参考，这两张也是备用封面
- 发布文案：`out/发布文案.txt`（标题、简介、话题）

## 时间轴（128 BPM，1 拍 = 0.469 s）
| 时间 | 画面 |
|---|---|
| 0:00 | 第 0 帧：「学累了 / 睡还是背？」，左边女孩翻书背，右边男孩趴着睡，挂钟 3 点，两根空的「记住了」柱 |
| 2.11 s | 胶囊翻成「30 分钟后考试」：两根柱一样高，都高过虚线「只休息」 |
| 3.05 s | 翻成「一周后」：背的那根掉到虚线、变灰 |
| 3.98 s | 叮 + 打勾「还领先」；4.45 s 出「优势没了」 |
| 7.0–15 s | 男孩醒来 → 伸懒腰 → 拿书，依次弹出 ① 什么时候睡 ② 睡多久 ③ 醒来干嘛；12.2 s 出「不止一个实验 d = 0.38」 |
| 15–30 s | 标签①变成标题；学「第 1 段」，钟每拍跳 5 分钟，22.5 s 走到 3 点叮一声，合书趴下 |
| 30–45 s | 挂钟变计时环：32.8 / 36.6 / 40.3 s 走到 10 / 30 / 60 分钟，各亮一句；41.25 s 结论填空 |
| 45–60 s | 计时环变闹钟，45.9 s 响；醒来接着学第 2 段；50.6–53.4 s 日历翻 7 天；54.4 s 记忆柱升起，仍高过「只休息」 |
| 60–75 s | 边演边出下午学习表 → 「午睡补不了熬夜」+「仅供参考」；68.4 s 截图闪光；70.1 s 出收藏按钮，71.25 s 小人点下去 |

## 数据来源
- Cousins 等 2019，《Sleep》，新加坡杜克-国大医学院：下午 3 点分三组各 1 小时（午睡 / 接着背 / 看电影休息），30 分钟后和一周后各考一次。30 分钟后睡的和背的一样好，都比休息的好；一周后只有睡的那组还明显比休息组记得多。所以片里只说「一周后只有睡过的还领先」，不说「背一小时不如睡一小时」。
- Leong 等 2023：睡 10–60 分钟都更清醒、心情更好；只有 30 分钟那组醒来学新东西更好；被试平时睡得少。
- Leong 等 2022：元分析，午睡后认知测验整体更好，d = 0.38。
- Lo 等 2017：午睡补不了熬夜。

## 重新出片
```bash
bash tools/build.sh    # 约 2 分钟；第一次会先在这里建 .venv，装 numpy 和 imageio-ffmpeg（自带 ffmpeg）
```
- 还需要 Node 18 以上和 Chromium。Kiro 沙箱里都有，脚本会自动找到；在别的电脑上，先在这个目录 `npm i playwright-core`，再设 `CHROME_EXE` 指向本机的 Chrome。
- 渲染时逐帧检查小人，结果写在 `build/frame_check.json`（7.1 s 之后缺小人的帧，应为空）。
- 只看几帧：`node tools/render.mjs --stills 0,2.2,3.2`，输出到 `build/stills/`。
- 只出封面参考图：`node tools/render.mjs --covers`（约 2 秒，`src/cover.js`；会检查四边留白和左下角是否为空）。
- 画面：`src/scene.js`（开场、先睡一觉）、`src/sections.js`（①②③、照着做），时间都按拍写。
- 音效：`tools/audio.py`，cue 表在 `cues()`（拍、音效、dB、声像）。
