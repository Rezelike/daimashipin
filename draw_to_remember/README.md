# Vibe知识大赏／画一笔，更好记？

这一期是独立制作的新片：Pillow 在原生 1920×1080 画布上编排镜头、手绘线条、数据和字幕，程序合成短音效，FFmpeg 渲染。新的夜间画室背景、同一成年人物的执笔与指向姿势，以及三件道具由图像模型生成，作为透明素材在代码中合成。人物全片站立或移动；没有旁白、配乐、画面抖动、点赞收藏提示或下期预告。没有使用既有 PR 的成片、脚本或封面。

## 事实核对

主要原文：[Wammes, Meade & Fernandes (2016), *The Quarterly Journal of Experimental Psychology*](https://dspacemainprd01.lib.uwaterloo.ca/server/api/core/bitstreams/994c229b-465a-4480-9586-75b3a9064d21/content)，DOI 10.1080/17470218.2015.1094494。原文实验 7 的方法与结果在第 16–17 页：47 名滑铁卢大学本科生随机分组，画组 24 人、写组 23 人；各学 66 个便于画的单词，每词 4 秒；约 10 分钟干扰任务后用 2 分钟自由回忆。论文第 17 页明确写出：画组回忆 23%，写组 14%。这两个数是**回忆出的单词比例**，不是成绩提高 23% 或 14%。封面、开头和结尾只使用这一实验的成对数字。

同一论文实验 1–6 也都报告画优于写；实验 6 将编码时间缩到 4 秒，实验 7 则是纯画组对纯写组。论文作者明言：实验材料仍是单个、易画的词，尚不能直接外推到复杂概念或真实课堂理解。其关于视觉、动作、语义共同作用的说法是机制解释，不是本片要展示的独立因果数字。

片中「苹果、钥匙、雨伞」是可画词的**演示例子**，不是宣称这三个词就是实验刺激。「挑词 → 简画 → 遮住回想」是将原实验的画词与自由回忆改为可操作练习；整个三步流程没有被该论文单独随机检验。不要宣传为「画图能替代理解课本」「所有知识都有效」「长久记忆保证提高」。

## 带秒数分镜

| 时间 | 画面动作与音效 | 中文／English |
|---|---|
| 0.00–2.11 | 第 0 帧执笔者已在画室竖纸上落笔；短击音；苹果线条连续长出 | 画一笔，更好记？／Draw it, or write it? |
| 2.11–3.98 | 玻璃板继续绘成；实验限制贴上，滴答 | 每个词，只给 4 秒／4 seconds per word |
| 3.98–8.00 | 同一次实验的结果同时揭晓：23% 对 14%；5 秒处强调「回忆更多」，6 秒出来源 | 66 个易画词 · 短时自由回忆／Wammes et al., 2016 · Exp. 7 |
| 8.00–15.00 | 他指向三道悬空门牌，依次亮起；无单独文字过场 | 先自己画，再试着想／Draw it yourself, then recall it. |
| 15.00–30.00 | 他在三座标本台挑苹果、钥匙、雨伞；每件道具按拍出现 | ① 挑能画的词／Start with words you can picture. |
| 30.00–45.00 | 他执笔在新的玻璃板上画圆与叶，线条生长 | ② 画出最明显的特征／Sketch the identifying features. |
| 45.00–60.00 | 他拉上画室遮帘，自己报出「苹果」，遮帘继续滑行 | ③ 遮住图，自己回想／Hide the sketch. Recall the word. |
| 60.00–75.00 | 墙上三件标本、研究结果与证据范围依次出现；人物指向，最后约 5 秒稳稳留屏，硬切结束 | 挑词 → 简画 → 遮住回想／Choose → sketch → recall；4 秒/词：画 23% · 写 14% |

整片 160 拍 = 75 秒，128 BPM，30 fps，1920×1080。段落起点 0、8、15、30、45、60 秒落在 0、16、32、64、96、128 拍；所有音效与对应画面事件使用同一拍号。没有音乐，也没有引用旧期的人物代码。图像模型素材与提示词见 `assets/PROMPTS.md`；发布时应按平台流程声明生成式素材。

## 生成与质检

```bash
python -m pip install -r requirements.txt
python render.py --all --ffmpeg ffmpeg
python verify.py --ffmpeg ffmpeg
```

Linux 需先安装 `fonts-noto-cjk` 和 `ffmpeg`。`out/分镜预览.png` 的 12 张画面有编号和秒数；`out/封面_横竖通用.png` 为**单张 1920×1440、4:3 文件**，中心 1080×1440 可直接裁成 3:4，重要标题、证据数字和三步都在中心裁区，裁区左下留空。`out/竖裁预览.png` 只供检查，不是第二张上传封面。

成片的镜头、字幕、绘画过程、数据揭晓和节拍由代码生成；声音是确定性程序合成，不含配乐。质检数值见 `out/验证结果.txt`。
