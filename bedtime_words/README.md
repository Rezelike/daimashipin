「学累了，睡会儿还是接着学？」（`sleep_or_cram/`）的续集，照搬它的做法：同一套渲染（Canvas + numpy）、两个小人、背景、配色和音效，结构按 lessons 结论 13。

## 数据来源（都对过原文）
- **Mazza 等 2016**，《Psychological Science》27(10):1321–1330：里昂大学 40 名 18–29 岁的年轻人，随机分两组，背 16 对斯瓦希里语—法语单词（例：nyanya = 番茄），每个都答对一次才结束；12 小时后再练到 16 个全对。白天组早 9 点背、晚 9 点复习；睡眠组晚 9 点背、睡一夜、早 9 点复习。
  - 背的时候两组一样（第一遍 4.6 个对 3.8 个，不显著）
  - 12 小时后复习前：睡眠组 10.3 个，白天组 7.45 个（d = 0.99）
  - 重新全对：3.05 轮对 5.80 轮（d = 2.00）
  - 一周后：15.2 个对 11.25 个（d = 2.93）
  - 半年后：8.7 个对 3.4 个
  - 后来另招的对照组（晚上背、睡一觉、早上只过一遍）一周后 11.25 个，和白天组一样：早上要复习到全对。所以片里说「默到全对」，不说「复习一遍」。
  - 两组最后都背会了 16 个，所以不说「早上背没用」，只说早上背的要多练一倍。
- **Gais、Lucas、Born 2006**，《Learning & Memory》13(3):259–262：美国高中生（母语英语）背英—德词表，也就是背德语单词。晚上 8 点背、当晚睡的，比早上 8 点背、隔 14 小时以上才睡的忘得少；同样晚上背，熬通宵再补觉，两天后还是记得少。作者的结论是：关键是学完几小时内睡着，跟几点学无关。
- **Cousins 等 2021**，《Sleep》44(3):zsaa210（和上期 Cousins 2019 同一个新加坡团队）：52 名本科生学蚂蚁和螃蟹的知识，晚 9 点对早 9 点、隔 12 小时复习。睡一觉后记得更多（d = 0.72），但复习没变快（d = 0.10）；一周后睡眠组只是数字上领先，不显著（d = 0.35）。所以表底写「换成背知识点，一周后差距不显著」。

## 重新出片
```bash
bash tools/build.sh                                   # 约 2 分钟：音效 -> 逐帧 -> MP4 -> 第 0 帧 -> 备用封面
node tools/render.mjs --lint                          # 每 0.25 s 查一遍文字：出画、互相压住（应为 0），小于 34 px 的列出来
node tools/sheet.mjs --mp4 out/背单词_75s_1080p.mp4    # 分镜预览（不加 --mp4 就直接从页面截；--times 0,1.5,3 只截这几个时间点，输出 build/quick.png）
node tools/render.mjs --stills 0,2.2,4.5              # 只看几帧，输出到 build/stills/
node tools/render.mjs --covers                        # 只出备用封面（会查竖封面那块的留白和左下角）
```
- 第一次运行会在这里建 `.venv`，装 numpy 和 imageio-ffmpeg（自带 ffmpeg）。还需要 Node 18 以上和 Chromium：Kiro 沙箱里都有，脚本会自动找到；在别的电脑上，先在这个目录 `npm i playwright-core`，再把 `CHROME_EXE` 指向本机的 Chrome。
- 画面：`src/scene.js`（开场、睡前背）、`src/sections.js`（①②③、照着做），时间都按拍写。上床的样子（床头板、枕头、被子）在 `src/kid.js`：`sit` 是坐在床上，`bed` 是躺下；窗户、单词卡、台灯、早饭在 `src/props.js`（`drawWindow`、`drawWordCard`、`drawBedLamp`、`drawBreakfastLocal`）；开场每张卡什么时候亮、什么时候忘，在 `scene.js` 的 `LEARN` 和 `FORGET`。
- 音效：`tools/audio.py`，cue 表在 `cues()`，共 189 个；第 0 帧一声重击；混音后按响度（BS.1770）统一到 -18.4 LUFS，和前两期一样。成片测得 -18.4 LUFS，真峰值 -1.9 dBFS。
